# TicTacToeGame-WinForms

A two-player Tic-Tac-Toe style game built with C# and Windows Forms.

## About the project

TicTacToeGame-WinForms is a simple desktop game played on a 12x12 board. Two players take turns placing their symbols: X and O.

The game counts points for every horizontal, vertical, or diagonal sequence of five matching symbols.

## Features

- 12x12 interactive game board
- Two-player mode: X and O
- Automatic score calculation
- Detection of horizontal, vertical, and diagonal sequences of five symbols
- Random cell colors that change after each move
- Start, Stop, and Restart controls
- Separate score and game-status panel
- Automatic game end when fewer than five empty cells remain

## Technologies

- C#
- .NET
- Windows Forms
- Visual Studio

## How to run

1. Clone or download this repository.
2. Open the `.sln` solution file in Visual Studio.
3. Build the project.
4. Run the application.

## Controls

- **Start** — starts a new game and resets both scores.
- **Stop** — pauses the current game.
- **Restart** — clears the board while keeping the scores.
